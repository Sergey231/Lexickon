## Принятые решения (сессия 2026-10-04)
- Источник оценки V1: JEV System One, по вызову на домен. Запасной вариант: датасет Lemma Atlas, который читается на бэкенде за тем же эндпоинтом (паков и локального датасета на устройстве нет). Деградация: только слова в доменах с корпусом, фразы дают `insufficient_data`, `confidence` может быть null (`estimate` = false, `basis` = частота на миллион с корпусом и версией).
- При переключении на запасной вариант: отличие из §1.0 не сохраняется, EX-1 сужается до слов, домены beta ограничиваются корпусами, личный эксперимент повторяется на словах разработки, при EX-3 ниже 20% beta без нового источника не запускается. Порядок: пилот, затем эксперимент; «повторить» только при переключении после первого эксперимента.
- Видение: оценка полезности — «ориентир», `basis` — пояснение к уровню, не разбор расчёта.
- Пилот KR-12: критерии считаются по каждому домену; совпадение уровня не менее 80%; ценность сверх частоты — вслепую выбранная автором оценка JEV не менее чем в 70% слов с расхождением (не менее 20 слов, варианты «JEV точнее / частота точнее / равноценно»); стабильность не менее 95% повторов (A-4). Окно по доле совпадения: от 80% до 1 − 20/N (200 слов: 80–90%, 400: 80–95%); выше окна — провал. По умолчанию 200 слов на домен, добор до 400. Диапазоны частот записываются в приложение до первого вызова JEV, для каждого домена отдельно. Правка описаний уровней — один раунд, затем новая выборка. Сравнение с универсальной LLM до beta не проверяется (риск принят).
- Ключ JEV получен (2026-10-04). Срок KR-12: до 2026-10-27 (срок актуальности фактов исследования) и до архитектуры.
- Личный эксперимент: база EX-2 — неделя измерений без Lexickon перед экспериментом (медианы по ручному журналу), не самооценка. Добавлены EX-5 (прирост очереди при том же лимите новых карточек) и контрметрика C-3 (доля пропущенных по низкой оценке слов, признанных нужными, ниже 20%). Условие beta: EX-2, EX-3, EX-4, EX-5.
- Контракт и модель данных: в ответе `version`; у `DomainAssessment` поля `estimate`, `version`, `confidence?`; кеш хранит перевод; лимит считается в вызовах оценки (100 в сутки, общий английский — тоже вызов); язык определяет бэкенд до вызова JEV и отклоняет только при уверенности 0.9 (422 `unsupported_language`).

## Не подтверждено явно (выбрано мной как рабочие значения)
- Лимит «100 вызовов оценки в сутки» при учёте общего английского: реальных поисков вдвое-втрое меньше; решить, оставить число или поднять до 200–300.
- Порог детектора языка 0.9; доля 20% в C-3; пары для проверки контекста (10 пар, различаются в 7); добор до 400 слов.
